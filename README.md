# Portfolio Website

A modern, responsive portfolio website featuring a smooth loading screen animation for an improved user experience.

## Features

- **Loading Screen**: Elegant loading animation that displays while the page loads
- **Responsive Design**: Fully responsive layout that works on desktop, tablet, and mobile devices
- **Smooth Animations**: Subtle hover effects and smooth scrolling navigation
- **Modern UI**: Clean, professional design with gradient accents
- **Sections**:
  - Hero section with introduction
  - About section with skills
  - Projects showcase
  - Contact information

## Technologies Used

- HTML5
- CSS3 (with custom properties and animations)
- Vanilla JavaScript

## How to Use

Simply open `index.html` in your web browser to view the portfolio website.

## Customization

To customize the portfolio for your own use:

1. Edit `index.html` to update personal information, projects, and contact details
2. Modify colors in `styles.css` by changing the CSS custom properties in `:root`
3. Adjust the loading screen duration in `script.js` by changing the `minLoadTime` value

## Loading Screen

The loading screen features:
- Animated spinner with gradient background
- Minimum 1-second display time for smooth UX
- Automatic fade-out once page content is loaded
- Smooth transition to main content
